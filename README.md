Features

Full CRUD — create, view, update, and delete job applications
Application tracking — record company, role, status, and notes for each application
Calendar view — see upcoming deadlines and interviews at a glance
Database-backed — built on Django's ORM for data modeling and queries
Template inheritance — consistent, maintainable page layout across views


Tech Stack

Backend: Python, Django
Database: Django ORM (SQLite locally)
Frontend: Django Templates, HTML/CSS
Deployment: Render

Why I built this
While actively job hunting, I applied to a lots of jobs and attended many seminars, but I kept forgetting dates  
and mixing up which event belonged to which company.So I wanted a simple tool to track every application I send out — 
where I applied, what stage I'm at, and when my next interview is — while practicing full-stack 
development with Django.
